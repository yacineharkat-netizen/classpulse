Notification keys (VAPID)

Made in this browser only; nothing is sent anywhere. Do it once. Keep the private key secret: it goes only in the secrets of Supabase.

Public key

In config.js of the site: vapidPublicKey: "…", and in Supabase as VAPID_PUBLIC_KEY.

Private key

Only in Supabase (Edge Functions › Secrets) as VAPID_PRIVATE_KEY.

Secret of the sending function

In Supabase as PUSH_SECRET, and in the table push_config (see the notes).
