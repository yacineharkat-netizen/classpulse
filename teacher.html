Sessions of this class

A session created by mistake can be corrected (title, date, time, type) or deleted with its attendance and quizzes. Open takes you to the live session. Group: the TD group or TP sub-group of the session (empty = whole class); only its students are expected. Unit: the same name (e.g. TP1) for the sessions of one lab run once per sub-group.

Registration of the students

A student registers once, from the home page or in class: student number, last name, first name, PIN. He must be in the official list (student number and last name). The phone he registers with becomes his class device (attendance and quizzes); after a registration made on a computer, the first device he uses in a session (phone or computer) becomes his class device. With another device he asks from the session page, for one session or as his new class device: you accept in the Live session tab or here. You can also decide yourself: Allow a new device. Too many wrong PINs: Unlock PIN. Somebody registered in his place, or PIN forgotten: Reset PIN.

What the lab assistants of this class see

The assistants of this class (Classes tab) find here the content you give to the students: documents of the student space, your resources (files and links pushed in class) and your demos. They can open it, download it if you allow it, and push it to the phones in the lab sessions they run. Everything they open or download is written in their activity log. They never change or delete anything. Read only removes the download buttons; it cannot stop a photo or a screenshot.

Each line below can differ from the class setting (for example: answers hidden, code downloadable).

Course content

Content of this class that the teacher shares with you. Open it to prepare the lab; push it to the phones from the Live session tab (list "Demo, link or file"). What you open is written in the activity log of the class.

Student space of this class

The students open ClassPulse on any device where they are signed in (home page › My documents), even outside a session, and see the documents you make visible here. A document is read on the site, with the name of the student printed over it. The PDF can be downloaded only if you allow it, document by document.

Add a simple link (a public web address)

Who reads what

For each document: who opened it, when, how long the page stayed on the screen, how far the student went down the page, and when the PDF or the attached file was downloaded. Click a student's name for all his documents.

My documents (private)

Your documents are stored in the ClassPulse database, not on the public site: nobody can read them without being registered in a class where you made them visible. One document = a page (HTML file), and optionally its PDF and an attached file (code zip…). The same document can be used in several classes.

Add or replace a document

Question bank

Fill the Excel template (one question per row, up to 5 options A-E, correct answers as letters, e.g. C or A,D). Importing a row with an existing ref replaces the question.

The question bank is shared by all your classes: the module name is what keeps the questions of each course apart. Pick an existing module in the list or type a new one.

Edit the question

Tick the correct option(s). Leave an option empty to remove it (2 to 8 options). A question with no correct option is a survey question (opinions, not graded).

Demos

Demos of the site, yours, and those your colleagues share. To send one to the phones, choose a session in the Live session tab first.

Publish a demo (a folder of web pages: HTML, JavaScript, CSS, images)

The demo is online at once, at an address of this site: no GitHub needed. Only web pages (they run in the browser); no server code (Python, PHP).

My resources

Links and files you can push to the phones from the Live session tab. They belong to you and are not shown to other teachers. Files stay private: the phones receive a temporary link valid for hours. Maximum MB per file (images, PDF, short videos...).

Export results

One Excel file for the selected class: attendance for every session, quiz marks out of 20, average without the lowest marks, statistics per question, and the list of students who left a quiz screen.

New class

Archive: the class leaves your lists, nothing is lost, and you can bring it back. Delete erases its students, sessions, attendance and marks for ever.

Lab assistants of this class

An assistant runs the lab (TP) sessions of this class with his own account: attendance, lab tests, random draw, bonus, pushing demos, viewing the students. He cannot delete anything, import lists, edit students, see the course sessions, the question bank, the exports or the student space. Everything he does is recorded below.

1. Create his account in Supabase (Authentication › Users › Add user, with his e-mail and a password). 2. Type the same e-mail here.

What the assistants did

Board check

Each numeric answer that depends on the board is checked with the values of every board. A student is flagged when another board fits his answers clearly better than the board he typed (he changed group, or read the wrong line of the table). Nothing changes until you click Recalculate: his numeric answers are then marked with the board you choose, minus the penalty you choose. The correction can be undone, it is shown on his phone (mark), in his profile and in the Excel export.
