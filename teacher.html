Official student list

Any Excel, OpenOffice/LibreOffice (.ods) or CSV file. Choose the file, then the sheet (one sheet per section), then check the three columns detected automatically. Other columns are ignored. Students who already registered themselves are matched by their student number. Template

Question bank

Fill the Excel template (one question per row, up to 5 options A-E, correct answers as letters, e.g. C or A,D). Importing a row with an existing ref replaces the question.

The question bank is shared by all your classes: the module name is what keeps the questions of each course apart. Pick an existing module in the list or type a new one.

Edit the question

Tick the correct option(s). Leave an option empty to remove it (2 to 8 options). A question with no correct option is a survey question (opinions, not graded).

Demos

Demos of the site, yours, and those your colleagues share. To send one to the phones, choose a session in the Live session tab first.

Publish a demo (a folder of web pages: HTML, JavaScript, CSS, images)

The demo is online at once, at an address of this site: no GitHub needed. Only web pages (they run in the browser); no server code (Python, PHP).

My resources

Links and files you can push to the phones from the Live session tab. They belong to you and are not shown to other teachers. Files stay private: the phones receive a temporary link valid for hours. Maximum MB per file (images, PDF, short videos...).
